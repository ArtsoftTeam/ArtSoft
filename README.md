## Скачать

Готовый установщик находится в разделе **Releases**:

**[Скачать ArtSoft-Setup.exe](https://github.com/ArtsoftTeam/ArtSoft/releases/tag/v1.0.0-beta)**

Запустите установщик, примите пользовательское соглашение и выберите папку установки. ArtSoft появится в меню «Пуск» и в списке установленных приложений Windows.

## Что умеет ArtSoft

- устанавливает выбранные программы из официальных источников;
- находит официальные драйверы видеокарты и материнской платы;
- показывает сведения о компьютере, нагрузку и накопители;
- предлагает игровые профили с ручным выбором изменений;
- очищает временные файлы и помогает обслуживать Windows;
- удаляет только выбранные необязательные встроенные приложения;
- поддерживает тёмную и мягкую светлую темы.

## ArtSoft Deployment

Специальный загрузочный образ ArtSoft Deployment упрощает установку Windows 11. До запуска установки можно выбрать редакцию Windows, профиль настройки, нужные программы и необязательные встроенные приложения.

Образ Windows, лицензионные ключи и исходный код программы в этом репозитории не публикуются. Для установки и активации Windows требуется законная лицензия.

## Безопасность

ArtSoft не удаляет приложения и не изменяет настройки Windows без подтверждения пользователя. Контрольная сумма установщика публикуется рядом с файлом в SHA256SUMS.txt.
